# Разработка

Рабочий цикл для лабораторной:

1. Создать `feature/...` от `develop`.
2. Изменить код и проверить его локально командой `.\.venv\Scripts\python.exe -m pytest -q`.
3. Сделать commit и push feature-ветки. Сайт, развернутый из `main`, пока не меняется.
4. После проверки слить feature-ветку в `develop`, затем `develop` в `main`.
5. После push в `main` проверить, что Jenkins успешно завершил тесты и доставил новую версию.

Эти шаги описывают ожидаемый процесс; Jenkins и webhook студент настраивает отдельно вручную.
